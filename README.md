## Featured Projects

### 🧩 CollabSpace

**AI Delivery Control Plane for engineering teams** · *In development*

Most project tools show what was planned. CollabSpace is designed to surface the gap between **what was planned, what is happening, what risks have appeared, and what needs to change** to deliver on time.

- 🏗️ **Layered backend** separating HTTP handling, business rules, and data access
- 🔐 **JWT authentication** with refresh-token rotation and bcrypt password hashing
- 🏢 **Multi-tenant design:** roles belong to workspace memberships, not users globally
- 🛡️ **Server-side authorization:** permissions come from database membership
- 🎯 **Delivery planning:** outcomes, goals, milestones, and a frozen plan baseline
- 🔗 **Task dependencies** with cycle prevention, topological sorting, and critical-path analysis
- 🕸️ **Execution graph UI** showing dependencies between work
- ⚡ **Real-time collaboration** with Socket.IO, workspace rooms, reconnect handling, and event ordering
- ⚛️ **Frontend state split:** Redux Toolkit for UI state and TanStack Query for server state
- 🧪 **Security-focused tests** covering tenant isolation and privilege boundaries

**Stack:** `React` `TypeScript` `Vite` `Redux Toolkit` `TanStack Query` `Node.js` `Express 5` `Socket.IO` `PostgreSQL` `Prisma` `Docker` `Vitest`

### 📚 PrepFlow

**Turns scattered study material into a realistic study plan** · *Built with AI coding tools*

PrepFlow doesn't just summarize notes. It answers *“what should I study next, and how should I use the time I have?”*

- 📄 Extracts topics and subtopics from study material
- 🔗 Links each topic to supporting evidence in the source
- 📊 Prioritizes topics and builds feasible daily plans with deterministic rules
- 🧠 **AI interprets, deterministic software decides:** the model does not decide whether a schedule fits the student's available time
- 📝 Submitted to the **DEV Hacktoberfest 2026 launch-weekend challenge** with a published write-up

**Stack:** `React` `Vite` `Tailwind CSS` `Express` `TypeScript` `PostgreSQL` `Prisma` `Ollama / Gemma` `Vitest`

**A one-tap outdoor walk planner** · *Built with AI coding tools* · [🌐 Live demo](https://pocketwalk.onrender.com)
