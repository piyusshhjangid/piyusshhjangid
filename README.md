## Featured Projects

### 🧩 CollabSpace

**An AI delivery control plane for engineering teams** · *In development*

CollabSpace is designed to help teams see the difference between what they planned, what is happening, what risks have appeared, and what they may need to change to deliver on time.

- Layered backend separating HTTP handling, business logic, and data access
- Multi-tenant workspaces with membership-based roles and server-side authorization
- JWT authentication with refresh-token rotation and bcrypt password hashing
- Goals, milestones, plan baselines, task dependencies, and critical-path analysis
- Execution graph and real-time collaboration with Socket.IO
- Security-focused tests for tenant isolation and privilege boundaries

**Stack:** React, TypeScript, Vite, Redux Toolkit, TanStack Query, Node.js, Express, Socket.IO, PostgreSQL, Prisma, Docker, Vitest

### 🏠 NCR PropertyDesk

**A real estate platform for property owners and home seekers** · [Live site](https://www.ncrpropertydesk.com/)

A deployed full-stack application for managing property listings and helping people discover homes.

- Property listings, owner tools, and map-based search
- AI-generated descriptions and price recommendations
- Cloudinary image handling and Redis caching
- Frontend on Vercel and backend on Render

**Stack:** React, Node.js, Express, MongoDB Atlas, Redis, Cloudinary, Gemini, Anthropic SDK, Docker Compose

### 📚 PrepFlow

**A study planner that turns learning material into a realistic schedule**

PrepFlow extracts topics from study material, links them to evidence in the source, and builds feasible daily plans. AI helps interpret the material; deterministic rules decide whether a plan fits the available time.

The project was submitted to the DEV Hacktoberfest 2026 launch-weekend challenge with a published write-up.

**Stack:** React, Vite, Tailwind CSS, Express, TypeScript, PostgreSQL, Prisma, Ollama, Gemma, Vitest

### 🚶 PocketWalk

**A one-tap outdoor walk planner** · [Live demo](https://pocketwalk.onrender.com)

Pick a walk based on current weather, then put your phone away.

- Live weather context from Open-Meteo
- Deterministic fallback when AI planning is unavailable
- Request limits and concurrency controls
- Automated backend and frontend tests
- Deployed on Render

**Stack:** React, Node.js, Express, TypeScript

## Open Source Journey

My open-source journey began with small, concrete changes: fixing bugs, improving documentation, and adding tests. Those contributions taught me how to work inside an existing codebase, follow project conventions, and make changes that maintainers can review.

Over **October 2026**, that work grew to **60 merged pull requests across 7 repositories**. I contributed most to ChatCops and OGCops, while also working on Toolbelt, Discord Bot, free-llm-api-hub, PrepFlow, and CollabSpace.

My ChatCops work expanded from widget fixes and test coverage into broader product and infrastructure improvements. I worked on accessibility and reduced motion, cross-origin requests, localization, content security policy support, PostgreSQL vector storage, AI reranking, and webhook reliability. I also added widget translations in 12 locales and translated disclosure text across 11 locales.

In OGCops, I contributed both interface improvements and new content templates, including cards for quizzes, ecommerce order updates, podcasts, job benefits, reader polls, SaaS deprecation notices, interviews, and blog benchmarks. Across the projects, I learned to pay attention to boundary cases such as invalid configuration, empty content, long text, concurrency, and failed network requests.

The work has helped me practice the full contribution cycle: understanding an issue, reproducing the problem, writing a targeted fix and tests, documenting behavior, and incorporating maintainer feedback. I’m continuing to improve at choosing the right scope and explaining the reasoning behind a change.

**Current contribution snapshot:** 60 merged PRs · 7 repositories · 0 open PRs  
**Full journal:** [Open Source Journey](https://github.com/piyusshhjangid/open-source-journey)
